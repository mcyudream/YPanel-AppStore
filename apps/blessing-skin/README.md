# Blessing Skin Server — Minecraft 皮肤站

自托管 Minecraft 皮肤/披风托管与外置登录站点：材质上传管理、3D 预览、皮肤库、插件系统（Yggdrasil API / Authme 集成等以插件形式提供）。本包采用官方 6.0.2 发行版（MIT，zip 自带 vendor，免 composer）。

## 安装说明

- **数据库**：向导「数据库」下拉选择纳管的 MySQL 实例（自动建库建号并注入凭据），或选「应用自带」后自行准备 MySQL。
- **PHP 运行时**：首次安装会自动构建（含 gd/zip/pdo_mysql 扩展，需要几分钟）；同节点同版本 PHP 应用共享运行时。
- 安装完成后访问站点地址，跟随 **Web 安装向导**完成初始化：数据库连接信息见面板「已安装应用 → 参数」（选择纳管实例时已自动生成），表前缀随意，其余默认。

## 数据与版本

- 站点根目录为应用目录的 `public/` 子目录（nginx root 已自动指向），配置、材质、插件都在其中，重装保留。
- 6.0.2 是官方 GitHub Releases 的最新发行版（v7/v8 尚未发布发行包，仅 dev 分支滚动开发）。
- 升级：官方未提供 6.x 之后的发行包，暂无升级路径；升级前备份站点目录与数据库。
