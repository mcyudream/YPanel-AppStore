# VictoriaLogs 集中日志存储

VictoriaMetrics 家族的开源日志数据库：**全字段自动索引**的全文检索、单机低资源（远低于 Elasticsearch）、兼容 Elasticsearch 写入协议与 Loki 查询生态。

在 YPanel 中的定位：**日志中心「集中存储」模式的后端**——配合应用商店的「Vector 日志采集器」，把多节点全部容器日志汇聚于此，即可在日志中心跨节点检索历史日志（容器重启/滚动后 tail 之外的内容也可查）。

## 使用步骤

1. 安装本应用（默认端口 9428，保留期默认 30 天，数据落在本应用目录 `data/`）；
2. 在需要采集的节点安装「Vector 日志采集器」，地址默认即可指向本应用（同网络容器名直连）；
3. 打开 **监控 → 日志中心 → 集中存储**，填入本应用地址（形如 `http://<宿主内网IP>:9428`）并检测；
4. 之后即可按容器/关键字/时间范围检索全部历史日志。

查询语言为 [LogsQL](https://docs.victoriametrics.com/victorialogs/logsql/)，面板内也提供高级查询框直接使用；VL 自带查询界面位于 `/select/vmui/`。
